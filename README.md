# DW Plumbing Solutions website

Static one-page site for DW Plumbing Solutions (Tweed Heads South NSW).

- `index.html`: the whole site, no build step
- `images/`: drop job photos here and swap the placeholders

## Deploy (Cloudflare Pages)
Connect this repo in Cloudflare Pages with no build command and output directory `/`.

Draft: remove the `noindex` meta tag in `index.html` before going live.
